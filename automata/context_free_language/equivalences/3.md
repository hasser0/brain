## Context free language is empty stack language

Given a grammar $G=\langle V, T, Q, S\rangle$, its language $L(G)$ is the empty
stack language for the pushdown automata $P=\langle\{q\},T,V\cup T,\delta,q,S\rangle$
such that

1. $\delta(q,\varepsilon,A)=\{(q,\beta): A\rightarrow \beta\quad\text{is a production rule }\}$
2. for every terminal symbol $\delta(q,a,a)=\{(q,\varepsilon)\}$
