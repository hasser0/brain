## Context free grammars

Given a grammar $G=\langle T, V, P, S\rangle$ it is a context free grammar iff
every production rule of $P$ has a single non terminal symbol on the left side.

Any string $w$ that is derivable from the starting symbol $S$ is part of the
language of $G$ which is a context free language $L(G)$
