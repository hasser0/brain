## Regular expressions

Regular expressions is a formal language where the base symbols are
$\varepsilon,0,1,a,b,c,\dots$
which are inductively generated by some operations. Given the regular expression
$\alpha, \beta$ we define

+ Concatenation: $\alpha\beta\equiv L(\alpha)L(\beta)$
+ Addition: $\alpha+\beta\equiv L(\alpha)\cup L(\beta)$
+ Closure: $\alpha^*\equiv \cup_{k=0}^\infty L(\alpha)^k$

The class of languages generated by regular expressions is the regular languages
class
