## Boolean operators

Given boolean expressions $\alpha,\beta$, the boolean operators truth tables are

1. $\alpha + \beta$ truth value equals $\alpha$ or $\beta$
2. $\alpha\cdot\beta$ truth value equals $\alpha$ and $\beta$
3. $\bar\alpha$ truth value equals  not $\alpha$

Similar to regular algebra, the multiplication **AND** precedes the addition
**OR** and the complement **NOT** precedes both
