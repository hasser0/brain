## Boolean expression

Boolean expressions is the language generated by the grammar
+ $T=\{0,1,+,\cdot,(,)\}$
+ $V$ is any set of symbols used as variables and their negative
+ The production rules are
    1. $S\rightarrow 1|0$
    2. $S\rightarrow (S)$
    3. $S\rightarrow \bar S$
    4. $S\rightarrow S + S$
    5. $S\rightarrow S\cdot S$
    6. For any variable $x\in V$ then $S\rightarrow x|\bar x$
