## Boolean function

The general boolean function is defined
$$
f:\{0,1\}^n\mapsto\{0,1\}
$$
This could be represented by a truth table or a boolean expression with $n$
variables

Since every boolean function has a corresponding truths table, therefore it has
a disjuntive normal form expression that represents the function. This means
that every boolean function has a boolean expression
