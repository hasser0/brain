## Subsets axiom

For every set $c$, exists a set $B$ such that any member $x$ of $B$ is in $c$
and satisfies $\phi(x)$, where $\phi$ is a formula in the formal language

### Paradoxes

This axiom prevents paradoxes by enforcing the condition $x\in c$, so that
arbitrary sets cannot be built such as $\{x: x\subseteq x\}$. We ensure subsets
are built from already existing sets anywhere in the hierarchy $V_\alpha$. In
addition, vague definitions are not allowed since the formula $\phi$ must be in
the formal language.

### Classes and sets

A class is defined as a collection of objects that can be defined. While this is
similar to the informal definition of a set the difference is that a set must be
crafted from these axioms and anything else cannot be a set.
