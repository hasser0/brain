## Formal theory

In general, a formal theory abstracts a way to communicate ideas in a formal
language and consists of

+ A set of **symbols** $\mathcal{S}$
+ **Expressions** as ordered tuples of symbols
+ **Well formed formulas** as a subset of expressions that is generated by a set
  of rules
+ **Axioms** as a set of wff
+ **Inference rules** as n-ary relations between relations
