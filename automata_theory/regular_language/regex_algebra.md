## Neutral

$$L + \varnothing = L$$
$$L\varepsilon = \varepsilon L = L$$

## Null element concat

$$L\varnothing = \varnothing L = \varnothing$$

## Idempotence

$$L + L = L$$

## Commutative

$$L+R = R+L$$

## Associative

$$L(RS) = (LR)S$$
$$L+(R+S) = (L+R)+S$$

## Distributive

$$L(R+S) = LR + LS$$
$$(R+S)L = RL + SL$$

## Closure

$$\varepsilon^* = \varepsilon$$
$$\varnothing^* = \varepsilon$$
$$L^* = (L^*)^*$$
