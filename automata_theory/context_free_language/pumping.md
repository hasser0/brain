## Pumping lemma

For any grammar $G$ exists a number $p$ such that for any string $w\in G$
if $|w|\ge p$ then $w=uvxyz$ such that

1. $i\ge 0$ $uv^ixy^iz\in G$ for any $i\ge 0$
2. $|vy|>0$
3. $|vxy|<p$

Proof

+ Let $b$ the max number of symbols of any production of $G$.
+ Let $p=b^{|V|+1}$
+ If $|w|\ge p$ then any parse tree $\tau$ has a path of $|V|+2$ symbols bottom
  upwards with $|V|+1$ variables. Let $\tau$ the parse tree with fewer of nodes
+ By the pigeon hole there is a variable $R$ that is repeated
+ Let $x$ the string generated by the lower $R$
+ Let $vxy$ be the string generated by the upper $R$

1. Replacing the upper $R$ with the lower $R$ and viceversa yields $uv^ixy^iz$
2. If $vy$ is empty then $w$ could be generated replacing upper $R$ with upper
  $R$ with fewer nodes, but $\tau$ is the parse tree with minimum number of
  nodes
3. The upper most $R$ is a subtree with height $|V|+1$ so $|vxy|<p$
