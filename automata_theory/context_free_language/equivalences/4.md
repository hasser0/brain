## Empty stack language has a context free grammar

Let $P=\langle Q,\Sigma,\Gamma,\delta,q_0,Z_0,F\rangle$ be a pushdown automata.
First of all transform $P$ into an equivalent pushdown automata such that

1. Empties its stack before accepting
1. Single final state: for each final state create an epsilon transition with
   the stack empty to the new unique final state
3. Either push or pop: each transition should either push or pop, but not both;
   break down the transition into two parts

For each $p,q\in Q$ define $A_{pq}$ as a variable of a grammar that generates a
string $w$ iff $(p,w,\varepsilon)\vdash (q,\varepsilon,\varepsilon)$.

### Case I: Base case

For every state $p$
$$
A_{pp}\rightarrow\varepsilon
$$

### Case II: None intermediate state the stack is empty

If a transition from $p$ to $r$ exists with label $a,X/\beta X$ and another
transition from $s$ to $q$ exists with label $b,\beta/\varepsilon$ then
$$
A_{pq}\rightarrow aA_{rs}b
$$

### Case III: Intermediate state empties the stack

If an intermediate state $r$ from $p$ to $q$ empties the stack then
$$
A_{pq}\rightarrow A_{pr}A_{rq}
$$
