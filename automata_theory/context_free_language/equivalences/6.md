## Context free languages are chomsky normal form languages

At each step we modify the existing rules such that the new rules keep
generating the same language

1. Add another starting symbol $S_0$ and add the rule $S_0\rightarrow S$ to
   avoid this to appear on the right side.
2. Remove epsilon rules, $A\rightarrow\varepsilon$, and for each rule such that
   $A$ is on the right side, add an extra rule producing the effect of an empty
   production.
3. Remove unit rules, $A\rightarrow B$, and for each rule $B\rightarrow u$
   replace with $A\rightarrow u$
4. Replace long rules $A\rightarrow u_1\dots u_k$ with subrules
    + $A\rightarrow u_1A_1$
    + $A_1\rightarrow u_2A_2$
    + ...
    + $A_{k-2}\rightarrow u_{k-1}u_k$
    and replace terminals $u_i$ with $U_i$ and add $U_i\rightarrow u_i$
