## Deterministic pushdown automata

A deterministic pushdown automata is a subclass of the pushdown automata such
that at every state, input and stack top there is exactly one option. Formally
it is a pushdown automata with the condition that for every state $p\in Q$,
$a\in\Sigma$ and $x\in\Gamma$ one and only one of

+ $\delta(q,a,x)$
+ $\delta(q,\varepsilon,x)$
+ $\delta(q,a,\varepsilon)$
+ $\delta(q,\varepsilon,\varepsilon)$

is not $\varnothing$

A language that is generated by a DPDA is called a deterministic context free
language
