## Acceptor

An acceptor is a machine that either outputs **Yes** or **No** depending on the
input and so they either accept or decline some input without any other
information.

There are other types of machines called transducers which not only accept or
decline some input, but interact with output peripherals

In this sense, an acceptor recognize a language, while a transducer transforms
it
