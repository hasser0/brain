## Memory components

+ Cache memory
    + Word
    + Line and blocks
    + Replacement policy
    + Cache coherence strategies
    + Tag directory
        + Valid bit
        + Modified bit
    + Physical address
        + Tag bits
        + Line bits
        + Offset bits
    + Direct memory mapping
        + Conflict miss
        + Each MM block is associated with a single cache line
    + Associative memory mapping
        + Expensive in size/cost and high temperature
        + Any block to any cache line
    + N-way set associative memory mapping
        + Trade off between direct and associative
        + Associative cache subset of N lines
+ Main memory
    + ROM - Non volatile
    + RAM - Volatile
        + SRAM
        + DRAM
+ Secondary memory
    + Removable
    + Fixed
        + HDD
            + Surfaces
            + Tracks
            + Sectors
        + SSD
