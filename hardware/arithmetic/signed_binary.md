## Signed binary

Unsigned binary numbers are not capable to represent negative values, therefore
other **schemas** must be used to describe both positive and negative values which
in turn should make hardware implementation and binary arithmetic easy and
performant. Some of these schemas are

+ Sign-magnitude
+ One's complement
+ Two's complement or radix complement

Different schemas are compared based on

+ Easy to implement
+ Performant
+ Maximize range of numbers
