## Control unit

The control unit is a chip or component of the CPU responsable of

+ Fetching and decoding instructions
+ Keep its internal mechanism working as expected according to the instruction
  set
+ Propagate signals to other components such as registers, ALU, memory or IO
  devices to execute the instruction

The control unit handle multiple registers to achieves its purpose such as

+ Instruction register
+ Data registers, used as a working memory
+ Program counter, used as a pointer to the next instruction
