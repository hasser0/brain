## Arithmetic logic unit

An ALU is not precisely defined since this is one of the first design decisions
that might be encounter while designing a chip. However as the name suggest,
this chip perform logical and arithmetic operations, to mention a few

+ Addition
+ Subtration
+ Multiplication
+ Division
+ Bitwise not
+ Bitwise and
+ Bitwise or

In general ALU have two input registers and a set of flags that changes the
behaviour of the chip that are called **opcode** as a group. The output, on the
other hand is a register and a set of flags
