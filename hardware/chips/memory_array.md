## Memory array

A memory array is an array of multiple **bit cells**, which are implemented
using different technologies with different tradeoffs, that store and retrieve
data.

Memory address is built from **word lines** and **bit lines**. Word lines acts
as a switch that enable or disables contact between bit lines and bit cells. Bit
lines acts as the input or output for data.
