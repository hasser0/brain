## Logic gate

Logic gates are the most basic abstraction in computer organization that
describes a boolean function $f$ as an interface and might be implemented in
multiple ways depending on cost, energy and size constrains

+ AND: logical connector and
+ OR: logical connector or
+ NOT: logical connector not
+ NAND: $\neg(p\land q)$
+ NOR: $\neg(p\lor q)$
+ XOR: $(p\land \neg q)\lor(\neg p\land q)$

Note: NAND logic gate can reproduce NOT, AND, OR gates
