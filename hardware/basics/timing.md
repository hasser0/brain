## Timing

For circuits in general, changes in inputs are not inmediately reflected in
output. There is a delay from the input's change until the output's response
stabilize and shows the new value.

The time from the input's changes to the output stabilization is called
**propagation delay**. On some cases changes in output appear before the final
result is propagated; the minimal time from input's changes to the first glitch
is called **contamination delay**
