## Algorithmic State Machine

ASM charts is a visual tool used to design digital systems concern with
sequential logic. Particularly ASM charts are able to describe Mealy and
Moore machines

+ State box: Output values in current state, independent of inputs
+ Decision box
+ Condition box: Output values conditionally

ASM are mainly used to create the control unit of digital circuits
