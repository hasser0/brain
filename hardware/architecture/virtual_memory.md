## Virtual memory

Virtual memory is a technique used in memory systems to extend main memory using
secondary memory. Suppose we got a 16GB DRAM, we could extend it using part of
the disk to 64GB, then we say that we got a virtual memory of 64GB with 16GB of
**physical memory**.

In this way physical memory works as a cache to virtual memory where blocks are
called pages
