## ROM

Non volatile memory or ROM(read only memory) keeps information even without
energy and similar to RAM, nowadays) it is also randomly accessed. ROM is a
combinational chip since its values are fixed

At first ROM memory was not writable, but other options have been created such
the following

+ PROM: Programmable ROM, can be written once using high voltage that breaks a
  connection to the ground, therefore creating
+ EPROM: Erasable PROM, can be written using UV for half an hour
+ EEPROM: Electrically EPROM, similar to EPROM but using electrons
