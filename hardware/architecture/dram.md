## DRAM

Dynamic RAM is a type of volatile memory array that is built from a transistor
that allows or blocks charge or discharge of a capacitor which acts as a memory
unit. It is the most suitable RAM memory for main memory.

+ Small in size
+ Cheaper
+ Needs constant refresh due maintainance and after reads
+ Slower due all operations involved during read and write

DDR DRAM or Double data rate is a DRAM that uses not only rising edge to
transfer data, but also falling edge
