## Flynn taxonomy

Flynn taxomony is a computer classification based on the number of simultaneous
instructions and the number data affected by those instructions

+ SISD: Single instruction, single data
+ SIMD: Single instruction, multiple data
+ MIMD: Multiple instruction, multiple data

The number of instructions and data imply that the number of control units and
processors(ALU and registers) differs. For mutiple instruction architectures,
data needs to be communicated across subparts either by shared memory or by
network
