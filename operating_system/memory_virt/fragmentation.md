## Fragmentation

Fragmentation is a problem in memory management that prevents the system from
using memory in the most efficient possible manner. There are two types of
fragmentation

+ External
+ Internal

External fragmentation appears when there are multiple small free memory chunks
which cannot be allocated because they are sparsed; internal fragmentation is
concerned with the process memory management which happens when it allocates
more memory than is being used.
