## Allocators

Allocators are the top level policies that specify on each situation the
position for newly allocated memory chunks, using the main memory management
mechanism such as

+ Split
+ Compact
+ Coalesce

The most known allocators are

+ Best fit
+ First fit
+ Worst fit
+ Seggregated free list
