## Free context grammar ambiguity

Given a grammar $G$ it is called ambiguous iff exists an string $w$ such that
it has more than one derivation tree.

Remark that it must have more than one **derivation tree** an not more than one
derivation, since a string $w$ could be obtained with different derivations(for
example lm and rm) and still express the same hierarchy

A string $w$ has two derivation trees iff $w$ has two different left derivations
from $S$
