## Graph

A graph, as an abstract data type, is a set of nodes connected by edges which is
denoted as $G=\langle V, E\rangle$. However there are multiple types of concrete
graphs

+ Directed - Undirected
+ Weight - Not weight
+ Simple - Not simple
+ Sparse - Dense - Complete
+ Cyclic - Acyclic
