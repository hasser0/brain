## Adjacency list

Given a graph, adjacency list is an implementation of an ADT graph such that

1. Each node is assigned an integer value from 0 to N-1
2. Edges are stored in an array of size N of linked lists

This implementation is mainly used for sparse graphs and in general most
applications are sparse
