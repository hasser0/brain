## Adjacency matrix

Given a graph with $N$ nodes, the adjacency matrix is an implemenation of a graph
ADT that work with a matrix $A$ of $N\times N$ where $A[i,j]$ is 1 when there
is a edje from node i to node j and 0 otherwise

The value could be the weight of the edge in a weighted graph and we could use a
triangular matrix to save space for an undirect graph
