## Abstract data type

An abstract data type is an abstraction similar to an algebraic structure. It
defines a domain on which it can be defined, a set of operations that it can
handle and a set of constrains that those operations must satisfy.

Abstract data types are implemented using data structures and can have more than
one implementation. For example, a stack is an ADT and can be implemented using
arrays and linked lists.
