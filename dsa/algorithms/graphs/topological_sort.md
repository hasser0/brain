## Topological sort

Topological sort is an algorithm that finds a linear ordering in a directed
graph. The linear ordering is found with the reverse order of the nodes that
processed such that the graph has not backward edges, otherwise a loop is
created and no such linear order exists. For that reason topological sort can
only be performed succesfully on DAGS
