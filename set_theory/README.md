## Symbols and defintions

Most of the symbols and definitions are justified by the corresponding axiom, but can also be
justified by

+ [Subset axiom](/set_theory/axioms/subset.md)
+ [Extensionality axiom](/set_theory/axioms/extensionality.md)

1. Empty set: $\varnothing$
2. Union set:
    + $\cup A$
    + $\cup_{X\in A} X$
4. Intersection set:
    + $\cap A$
    + $\cap_{X\in A} X$
3. Power set: $\mathcal{P}A$
5. Set by extension: $\{x_1, x_2, x_3, x_4\}$
6. Set by comprehension: $A = \{x\in S:\phi(x)\}$
