## Integers

Let $\omega$ be the set of natural numbers and $R$ be the relation such that
$(m,n) R(p,q)$ implies $m+q = n+p$ then the integers could be defined as the
quotient set $(\omega\times\omega)/R$.

Relations or functions defined on $Z$ using notions from $\omega$ are not
necessarily well defined. For example $f: Z\mapsto Z$ defined as
$(p,q)\mapsto (p,0)$ yields different results for different members of the same
equivalence class. As such any well defined relation or function must yield the
same result independent of the selected member.

This set construction of the integers has equivalent definitions for the
addition, multiplication and ordering relation that verifies the expected
algebraic properties
