## Arithmetic

Any arithmetic operator can be described using the recursion theorem

Addition

1. $A_m(0) = m$
2. $A_m(n^+) = A_m(n)^+$

Multiplication

1. $M_m(0) = 0$
1. $M_m(n^+) = A_m(n)+m$

Exponentiation

1. $E_m(0) = 1$
1. $E_m(n^+) = E_m(n)\cdot m$
