## Rationals

Similar to how integers are constructed from naturals with respect to addition,
rationals are constructed from integers with respect multiplication. For this
purpose, define the relation $R:(Z\times Z)\mapsto (Z\times Z)$ such that
$(a,b)$ and $(c,d)$ are related iff $a\cdot d = b\cdot c$

Then rationals are defined as the quotient set $Q = (Z\times Z')/R$ where
$Z'=Z-\{0_Z\}$. This definitions is a new equivalence class on which we should
define and prove right all previous functions, relations, operators and
properties.
