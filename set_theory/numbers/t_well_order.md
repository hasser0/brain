## Well order

Any subset of the naturals $\omega$ has a minimum element

### Implications

+ [Strong induction](/set_theory/numbers/t_strong_induction.md)

### Proof

Let $A$ be any subset of the naturals and $B$ the set of all naturals such that
no smaller element is in $A$. If $A$ has non minimum element, then $B$ would be
empty which leds to a contradiction
