## Peano system

A triple $\langle N, S, e\rangle$ consist of a set  $N$, a function
$S:N\mapsto N$ and a member $e\in N$ such that
1. $e\notin \text{ran } S$
2. $S$ is one to one
3. $A\subset N$ such that $e\in A$ and closed under $S$ equals $N$

### Naturals is a Peano system

$\langle \omega, \sigma, 0\rangle$ is a Peano system where $\omega$ is the set
of naturals, $\sigma$ is the successor operation and $0=\varnothing$
