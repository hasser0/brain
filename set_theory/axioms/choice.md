## Axiom of choice(Form 1)

For any relation $R$ there is a function $H\subseteq R$ with
$\text{dom }H = \text{dom }R$

## Axiom of choice(Form 2)

For any function $H$ with domain $I$, if $\forall i\in I:H(i) \neq \varnothing$
then $\textsf{X}_{i\in I} H(i) \neq \varnothing$
