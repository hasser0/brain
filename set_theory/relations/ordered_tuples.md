## Ordered tuples

Ordered tuples are the n-ary generalization of ordered pairs.
$$
\langle x_1,\dots,x_n\rangle = \langle\langle x_1,\dots, x_{n-1}\rangle, x_n\rangle
$$

## Infinite ordered tuples

For arbitrarily large tuples it is simpler to define them as functions. If $I$
is any set and $H$ is a function with $\text{dom }H = I$, then

If $H(i)=\{a_i,b_i,c_i\} \dots H(j)=\{a_j,b_j,c_j\}$
then $\langle a_i, \dots , a_j\rangle \equiv \{\langle i, a_i\rangle,\dots ,\langle j, a_j\rangle \}$
