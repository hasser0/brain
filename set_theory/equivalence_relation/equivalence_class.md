## Equivalence class

For any arbitrary $x$ and any relation $R$ the set $[x]_R$ is
$[x]_R = \{t: xRt\}$ when $x\in\text{fld }R$ and $R$ is an equivalence relation
then $[x]_R$ is called the equivalence class of $x$ modulo $R$
